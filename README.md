# Habit Rabbit

**Habit Rabbit** — веб-приложение для совместного формирования полезных привычек и отслеживания личного прогресса. Пользователи могут создавать группы, ставить цели, выполнять задания и получать награды за свои достижения.

## Основные возможности

- Регистрация и авторизация пользователей.
- Создание привычек и присоединение к существующим группам.
- Добавление заданий и отслеживание их выполнения.
- Просмотр статистики и прогресса участников.
- Ведение заметок.
- Система достижений и внутриигровых наград.
- Магазин предметов для виртуального питомца.
- Интерактивный виртуальный питомец с анимацией и эмоциями.
- Редактирование профиля и настройка аватара.

## Используемые технологии

| Технология | Назначение |
|---|---|
| JavaScript | Основной язык разработки |
| React | Создание пользовательского интерфейса |
| React Router | Маршрутизация между страницами |
| HTML | Структура приложения |
| CSS | Стилизация и адаптивная вёрстка |
| Vite | Сборка и разработка проекта |
| REST API | Взаимодействие с серверной частью |
| JWT | Авторизация пользователей |
| Live2D Cubism | Анимация виртуального питомца |
| Vercel | Развёртывание клиентской части |

## Особенности реализации

- Компонентная архитектура на React.
- Разделение пользовательского интерфейса на переиспользуемые компоненты.
- Реализация маршрутизации с помощью React Router.
- Взаимодействие с серверной частью через REST API.
- Авторизация пользователей с использованием JWT.
- Сохранение токена авторизации в localStorage.
- Обработка ответов сервера и пользовательского ввода.
- Создание адаптивного интерфейса для разных размеров экранов.
- Интеграция Live2D Cubism для отображения интерактивного виртуального питомца.
- Реализация игровых механик: достижений, монет, заданий и магазина предметов.

## Статус проекта

На данный момент приложение недоступно для полноценного запуска: серверная часть не отвечает после прекращения действия подписки на использовавшуюся серверную инфраструктуру.
При этом клиентская часть проекта была реализована и развёрнута отдельно. Скриншоты в репозитории демонстрируют интерфейс и реализованный пользовательский функционал.
